# Дашборд «Пульс»

Соберите один экран в DataLens, Power BI или Tableau. Данные — витрины dbt или CSV из `seeds/`.

## Первый экран

- MRR и ARPU на 30.09.2026.
- Отток за 90 дней.
- Доля failed payments и сумма возвратов.
- Один график динамики net revenue по месяцам.
- Один разрез: каналы или тарифы.

## Определения

- **MRR** — сумма `monthly_price` активных подписок на дату.
- **ARPU** — MRR / число активных пользователей.
- **Отток 90 дней** — отмены за июль–сентябрь / активные на 1 июля.
- **Net revenue** — paid минус refunded, только `is_valid_lifecycle`.

## Проверка перед публикацией

1. Сумма MRR совпадает с запросом из `kpi.sql`.
2. Период и часовой пояс подписаны.
3. У каждого графика есть подпись, единица и источник.
4. Фильтры не меняют определение метрики.
5. Есть владелец и дата обновления.
