# Шаблон sales-дашборда

Данные: `bi-orders.csv`. Период: январь–февраль 2026.

## Верхний ряд — KPI
| Показатель | Формула | Формат |
|---|---|---|
| Выручка | сумма revenue без возвратов | млн ₽ |
| Заказы | число order_id | шт. |
| Средний чек | выручка / заказы | ₽ |
| Конверсия | заказы / визиты (визиты добавить из веб-аналитики) | % |

## Средний ряд
- Линия: выручка по неделям, разрез по каналу.
- Столбики: выручка по городам, сортировка по убыванию.
- Фильтры: период, канал, город.

## Нижний ряд
- Таблица топ-5 городов: выручка, заказы, средний чек, доля возвратов.
- Подпись: дата обновления и определение выручки.

## Проверка
1. Сумма по таблице сходится с KPI выручки.
2. Возвраты не попадают в выручку и подписаны отдельно.
3. На экране не больше четырёх KPI и двух графиков.
