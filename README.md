# Лаборатория аналитики

Учебник, тесты и тренажёры по аналитике, статистике, теории игр, вероятности, SQL, Excel, Python и ИИ. Статический сайт без сборки и бэкенда.

Сайт: https://chipsfirst.github.io/analytics_lab/

## Быстрый старт

```bash
python3 -m http.server 8123
# http://localhost:8123
```

Офлайн: скачайте `analytics-lab-offline.zip`, распакуйте и запустите `start.command` (macOS/Linux) или `start.bat` (Windows). Либо откройте сайт и установите его как приложение.

## Что внутри

12 разделов, 91 глава, 182 вопроса, 63 тренажёра, 9 демонстраций, 8 игр, две песочницы, маршруты обучения, шпаргалка, словарь на 77 терминов, BI-лабораторные, шаблоны дашбордов, два сертификационных теста, сквозной проект, практика на трёх датасетах, 12 кейсов с открытым ответом, калькуляторы, Python-блокнот, главы об ИИ, слабые темы с экспортом конспекта, поиск и прогресс.

## Структура

| Путь | Назначение |
|---|---|
| `js/app.js` | роутер и отрисовка страниц |
| `js/data.js` | каркас контента |
| `js/topics/` | главы и вопросы: по файлу на раздел |
| `js/core/` | прогресс, поиск, маршруты, шпаргалка, словарь |
| `js/features/` | тренажёры, игры, демонстрации |
| `js/sandboxes/` | песочницы SQL и Python, воркер |
| `vendor/` | движок `sql.js` |
| `data/` | датасет кейса |
| `selftest.js` | проверки контента и логики |
| `sw.js`, `manifest.webmanifest`, `icon*` | PWA |
| `tools/make-offline.py` | сборка офлайн-архива |
| `analytics-lab-offline.zip` | готовая офлайн-сборка |

## Правки и проверка

Контент правится в `js/topics/<раздел>.js`. После изменений:

```bash
node selftest.js
python3 tools/make-offline.py
```

Затем поднимите `VERSION` в `sw.js`. Пуш в `main` запускает проверку и деплой GitHub Pages.

## Ограничения

- Python-песочница при первом запуске скачивает Pyodide — нужен интернет.
- SQL-песочница не работает через `file://`: нужен локальный сервер из архива.
- Прогресс хранится в браузере; для переноса есть экспорт и импорт JSON.
