# Лаборатория аналитики

Учебник, тесты и тренажёры по данным, аналитике, статистике, теории игр, вероятности, SQL, Excel, Python, машинному обучению, временным рядам, причинному выводу, этике и приватности. Статический сайт без сборки и бэкенда.

Сайт: https://chipsfirst.github.io/analytics_lab/

## Быстрый старт

```bash
python3 -m http.server 8123
# http://localhost:8123
```

Офлайн: скачайте `analytics-lab-offline.zip`, распакуйте и запустите `start.command` (macOS/Linux) или `start.bat` (Windows). Либо откройте сайт и установите его как приложение.

## Что внутри

16 разделов, 121 глава, 243 вопроса, 86 тренажёров, 10 демонстраций, 8 игр, две песочницы, шесть маршрутов обучения, шпаргалка, словарь на 77 терминов, BI-лабораторные, шаблоны дашбордов, два сертификационных теста, сквозной проект, практика на шести датасетах, 12 кейсов, тренажёр промптов, симулятор подглядывания в A/B, карточки с экспортом в Anki, командная палитра Ctrl+K, раздел о данных, типы аналитики, калькуляторы, Python-блокнот, главы об ИИ, слабые темы с экспортом конспекта, блоги и книги по аналитике, поиск и прогресс.

## Данные

Все датасеты синтетические, без пропусков; ключи строк уникальны. Они используются в практике, кейсах, BI-лабораторных и Python-блокноте.

| Файл | Строк | Что внутри |
|---|---:|---|
| `data/ab-test.csv` | 1 200 | По 600 пользователей в группах A и B; 51 и 87 конверсий, выручка. |
| `data/case-orders.csv` | 800 | По 400 посетителей в группах; 43 и 53 покупателя, заказы, выручка, обращения в поддержку, время загрузки. |
| `data/churn.csv` | 600 | 128 ушедших клиентов (21,3%); срок, платёж, обращения в поддержку. |
| `data/marketing.csv` | 90 | 30 дней по трём каналам: расходы, клики, конверсии, выручка. |
| `data/bi-orders.csv` | 28 | Заказы за январь–февраль 2026, 3 возврата, 11 клиентов. |
| `data/dirty-customers.csv` | 24 | Грязный датасет для практики очистки: дубли, пропуски, разные форматы дат, городов и сумм. |

В BI-примере AOV = 268 100 / 28 = 9 575 ₽: в знаменателе все оформленные заказы. Чек по оплаченным заказам — 268 100 / 25 = 10 724 ₽.

## Правки и проверка

Контент правится в `js/topics/<раздел>.js`. После изменений:

```bash
node selftest.js
python3 tools/check-version.py
python3 tools/make-offline.py
```

Версия хранится в `VERSION`; она продублирована в `sw.js` и `index.html`, а `check-version.py` проверяет совпадение. Пуш в `main` запускает проверку и деплой GitHub Pages.

## Полнота

Сильнее всего покрыты статистика (18 глав, 38 вопросов), BI (13/21), ИИ (10/23), аналитика (9/21), данные (6 глав, 16 вопросов, 8 тренажёров). «Полезное» — 7 глав, 12 вопросов, 4 тренажёра; регрессия и классификация — по 7 глав и 14 вопросов. Новые разделы: временные ряды (5/10), причинный вывод (5/10), этика и приватность (5/10).

Шесть маршрутов обучения покрывают 13 из 16 разделов; не покрыты теория игр, этика и «Полезное». Поиск индексирует главы, тесты и словарь, но не кейсы, демонстрации и игры. Для практики очистки добавлен грязный датасет `data/dirty-customers.csv` с задачами.

## Ограничения

- Python-песочница при первом запуске скачивает Pyodide — нужен интернет.
- SQL-песочница не работает через `file://`: нужен локальный сервер из архива.
- Прогресс хранится в браузере; для переноса есть экспорт и импорт JSON.
- Датасеты небольшие и синтетические. `marketing.csv` даёт 90 дней и подходит для знакомства с временными рядами, но для полноценного прогноза нужен более длинный ряд. Остальные без дат; для сложных разрезов и сегментов их мало.
