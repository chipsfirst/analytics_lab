# Лаборатория аналитики

Учебник, тесты и тренажёры по данным, аналитике, статистике, теории игр, вероятности, SQL, Excel, Python, машинному обучению, временным рядам, причинному выводу, этике и приватности. Статический сайт без сборки и бэкенда.

Сайт: https://chipsfirst.github.io/analytics_lab/

## Быстрый старт

```bash
python3 -m http.server 8123
# http://localhost:8123
```

Офлайн: скачайте `analytics-lab-offline.zip`, распакуйте и запустите `start.command` (macOS/Linux) или `start.bat` (Windows). Либо откройте сайт и установите его как приложение.

## Что внутри

17 разделов, 138 глав, 277 вопросов, 89 тренажёров, 10 демонстраций, 8 игр, две песочницы, семь маршрутов обучения, шпаргалка, словарь на 77 терминов, BI-лабораторные, шаблоны дашбордов, два сертификационных теста, сквозной проект, большой проект на четырёх таблицах, открытый проект по подписке и dbt-проект с тестами и живым дашбордом, практика на четырнадцати датасетах, 12 кейсов, тренажёр промптов, симулятор подглядывания в A/B, карточки с экспортом в Anki, командная палитра Ctrl+K, раздел о данных, типы аналитики, калькуляторы, Python-блокнот, главы об ИИ, слабые темы с экспортом конспекта, блоги и книги по аналитике, поиск и прогресс.

## Правки и проверка

Контент правится в `js/topics/<раздел>.js`. После изменений:

```bash
node selftest.js
python3 tools/check-version.py
python3 tools/make-offline.py
```

Версия хранится в `VERSION`; она продублирована в `sw.js` и `index.html`, а `check-version.py` проверяет совпадение. Пуш в `main` запускает проверку и деплой GitHub Pages.

## Ограничения

- Python-песочница при первом запуске скачивает Pyodide — нужен интернет.
- SQL-песочница не работает через `file://`: нужен локальный сервер из архива.
- Прогресс хранится в браузере; для переноса есть экспорт и импорт JSON.
- Большой, открытый и dbt-проекты синтетические: 27–29 тысяч строк и четыре таблицы, но реальные выгрузки грязнее и сложнее по схеме. В открытом проекте нет автопроверки: оценивать себя придётся по рубрике. Для запуска dbt нужны Python 3.10+ и установка `dbt-duckdb`. `marketing.csv` даёт 90 дней и подходит для знакомства с временными рядами; для полноценного прогноза нужен более длинный ряд.
