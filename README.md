# Аналитика-лаб

Статический сайт-тренажёр: учебник, тесты, тренажёры, интерактивные демонстрации и игры по аналитике данных, статистике, теории игр, теории вероятностей, SQL и Excel.

Без сборки и без бэкенда. Внешняя зависимость одна — `sql.js` для песочницы, он лежит в `vendor/`.

## Возможности

- **Учебник** — 10 разделов, 58 глав с формулами, таблицами и примерами.
- **Тесты** — 114 вопросов с разбором; результат и ошибки запоминаются.
- **Тренажёры** — задачи генерируются заново: расчёт метрик, статистика, вероятность, равновесие Нэша, SQL-запросы, формулы Excel, срезы и типы Python, MAD и усечённое среднее, предсказание по уравнению регрессии, precision и recall, Пуассон, голосование kNN и леса, k-средние.
- **Демонстрации** — ЦПТ, калькулятор размера выборки для A/B, регрессия к среднему, доверительные интервалы, парадокс Симпсона, ошибки I и II рода, бутстрап, перестановочный тест, ROC-кривая с порогом.
- **Игры** — Монти Холл, дилемма заключённого, блиц, калибровка вероятностей, аудит отчёта, многорукий бандит.
- **Песочница SQL** — настоящая база в браузере, любые запросы.
- **Прогресс** — прочитанные главы и лучшие результаты хранятся в `localStorage`; кнопка «Разобрать ошибки» возвращает вопросы, где были ошибки.
- **Поиск** по главам и вопросам, ссылки на конкретную главу (`#/theory/sql/5`).
- **PWA** — установка на телефон и офлайн-режим после первого открытия.

## Локальный запуск

Двойной щелчок по `index.html` — большая часть сайта работает и так.

Песочница SQL и service worker требуют http:

```bash
python3 -m http.server 8123
# затем http://localhost:8123
```

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | каркас: шапка, поиск, меню, контейнер |
| `style.css` | оформление, светлая и тёмная тема |
| `data.js` | каркас контента, разделы подключаются из `topics/` |
| `topics/*.js` | главы учебника и банки вопросов: по файлу на раздел |
| `trainers.js` | генераторы задач и проверка ответов |
| `games.js` | пять игр |
| `demos.js` | интерактивные демонстрации на canvas |
| `search.js` | индекс и поиск по контенту |
| `progress.js` | прогресс в localStorage |
| `sandbox.js` | песочница SQL на `sql.js` |
| `app.js` | роутер на хешах и отрисовка страниц |
| `vendor/` | `sql.js` (движок песочницы) |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | PWA |
| `selftest.js` | самопроверка контента и логики |

## Как добавить контент

**Глава.** В файле раздела `topics/<раздел>.js` добавьте объект в `chapters`:

```js
{ title: "Название главы", html: `<p>Текст, таблицы, формулы.</p>` }
```

**Вопрос теста.** В массив `quiz`. Правильный вариант всегда первый (`correct: 0`), интерфейс перемешивает варианты сам:

```js
{ q: "Вопрос?", options: ["Верный", "Неверный", "Ещё неверный"], correct: 0, explain: "Разбор." }
```

**Тренажёр.** В `trainers.js` напишите генератор и добавьте его в `window.TRAINERS[раздел]`:

```js
{
  prompt: "<p>Условие</p>",
  solution: "<p>Пошаговое решение</p>",
  answer: { type: "number", value: 12.5, tol: 0.05 }
  // или { type: "choice", options: [{ text: "A1", ok: true }, { text: "A2", ok: false }] }
}
```

**Демонстрация.** В `demos.js`: `{ title, tag, mount(root) }`, где `mount` рисует интерфейс и возвращает функцию очистки (если нужны таймеры).

## Проверка

```bash
node selftest.js
```

Прогоняет каждый генератор 300 раз, проверяет структуру контента, прогресс, поиск и что верный ответ принимается, а неверный — нет.

## Публикация на GitHub Pages

1. Запушьте файлы в ветку `main`.
2. **Settings → Pages → Source: GitHub Actions**.
3. Каждый push запускает `selftest.js` и деплоит только при успешной проверке.

Сайт будет доступен по адресу `https://<пользователь>.github.io/<репозиторий>/`; все пути относительные.

## Обновление и кеш

Service worker отдаёт файлы из кеша. После правок поднимите `VERSION` в `sw.js` (например, `v2`) — иначе у вернувшихся посетителей останется старая копия.

## Ограничения

- Прогресс привязан к браузеру: не синхронизируется между устройствами и теряется при очистке данных.
- Песочница SQL не работает при открытии через `file://` — браузер не отдаёт wasm с локального диска.
- Тёмная тема включается системной настройкой ОС; ручного переключателя нет.
