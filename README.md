# Аналитика-лаб

Статический сайт-тренажёр: учебник, тесты, тренажёры, интерактивные демонстрации и игры по аналитике данных, статистике, теории игр, теории вероятностей, SQL, Excel и Python, плюс практические чек-листы по визуализации, заметкам и выступлениям.

Без сборки и без бэкенда. Внешняя зависимость одна — `sql.js` для песочницы, он лежит в `vendor/`. Python-песочница при первом запуске скачивает Pyodide с CDN.

## Возможности

- **Учебник** — 11 разделов, 69 глав с формулами, таблицами и разобранными числовыми примерами.
- **Маршрут обучения** — три последовательности с прогрессом: аналитик с нуля, статистика для экспериментов, Python и данные.
- **Шпаргалка** — таблица «задача → метод → допущения → что проверить».
- **Тесты** — 148 вопросов с разбором; результат и ошибки запоминаются, есть режим «Разобрать ошибки».
- **Мини-тесты** — после каждой главы кнопка «Проверить себя · 3 вопроса» с мгновенным разбором.
- **Тренажёры** — 59 генераторов задач: метрики, статистика, вероятность, равновесие Нэша, SQL, Excel, Python, регрессия, precision/recall, kNN и k-средние, выбор графика и типа заметки. У каждой задачи есть пошаговое решение.
- **Демонстрации** — ЦПТ, калькулятор размера выборки для A/B, регрессия к среднему, доверительные интервалы, парадокс Симпсона, ошибки I и II рода, бутстрап, перестановочный тест, ROC-кривая.
- **Игры** — Монти Холл, дилемма заключённого, блиц, калибровка вероятностей, аудит отчёта, многорукий бандит.
- **Песочница SQL** — настоящая база в браузере, любые запросы.
- **Песочница Python** — блокнот с ячейками на Pyodide. Ядро загружается по кнопке, чтобы не тратить трафик при открытии страницы; код выполняется в отдельном воркере без доступа к странице и сети.
- **Калькулятор выборки** — в главе про A/B: конверсии, мощность, α и нужное число наблюдений.
- **Прогресс** — главы и результаты тестов в `localStorage`; экспорт и импорт в JSON для переноса между браузерами.
- **Навигация** — оглавление с подсветкой текущей главы, переходы «предыдущая/следующая» в конце главы.
- **Поиск** по главам и вопросам, ссылки на конкретную главу (`#/theory/sql/5`).
- **PWA и офлайн** — установка на телефон и офлайн-режим после первого открытия; отдельный архив для запуска с диска: `analytics-lab-offline.zip` и страница `#/offline`.

## Локальный запуск

Двойной щелчок по `index.html` — большая часть сайта работает и так: главы, тесты, тренажёры, игры, демо, поиск, прогресс.

Песочницы SQL и Python, а также service worker требуют http:

```bash
python3 -m http.server 8123
# затем http://localhost:8123
```

## Офлайн-версия

`analytics-lab-offline.zip` — тот же сайт без внешних зависимостей, кроме Pyodide. Внутри `start.command` (macOS/Linux) и `start.bat` (Windows): они поднимают локальный сервер на `http://localhost:8000`. Без сервера (просто `index.html`) песочница SQL недоступна, потому что браузер не отдаёт wasm с диска.

Пересобрать архив после правок:

```bash
python3 tools/make-offline.py
```

Архив не обновляется автоматически: после изменения контента или кода запустите сборку и закоммитьте новый ZIP.

## Как добавить контент

**Глава.** В файле раздела `topics/<раздел>.js` добавьте объект в `chapters`:

```js
{ title: "Название главы", html: `<p>Текст, таблицы, формулы.</p>` }
```

**Вопрос теста.** В массив `quiz`. Правильный вариант всегда первый (`correct: 0`), интерфейс перемешивает варианты сам:

```js
{ q: "Вопрос?", options: ["Верный", "Неверный", "Ещё неверный"], correct: 0, explain: "Разбор." }
```

**Тренажёр.** В `trainers.js` напишите генератор и добавьте его в `window.TRAINERS[раздел]`:

```js
{
  prompt: "<p>Условие</p>",
  solution: "<p>Пошаговое решение</p>",
  answer: { type: "number", value: 12.5, tol: 0.05 }
  // или { type: "choice", options: [{ text: "A1", ok: true }, { text: "A2", ok: false }] }
}
```

**Демонстрация.** В `demos.js`: `{ title, tag, mount(root) }`, где `mount` рисует интерфейс и возвращает функцию очистки (если нужны таймеры).

## Проверка

```bash
node selftest.js
```

Скрипт прогоняет каждый генератор 300 раз, проверяет структуру контента, ссылки, маршруты, шпаргалку, прогресс, поиск и что верный ответ принимается, а неверный — нет. Тот же прогон выполняется в GitHub Actions перед деплоем.

## Публикация на GitHub Pages

1. Запушьте файлы в ветку `main`.
2. **Settings → Pages → Source: GitHub Actions**.
3. Каждый push запускает `selftest.js` и деплоит только при успешной проверке.

Сайт будет доступен по адресу `https://<пользователь>.github.io/<репозиторий>/`; все пути относительные.

## Обновление и кеш

Service worker отдаёт файлы из кеша. После правок поднимите `VERSION` в `sw.js` (например, `v20`) — иначе у вернувшихся посетителей останется старая копия. Затем пересоберите офлайн-архив.

## Ограничения

- Прогресс хранится локально; для переноса используйте экспорт и импорт JSON.
- Песочница SQL не работает при открытии через `file://` — браузер не отдаёт wasm с локального диска; используйте локальный сервер или архив.
- Песочница Python при первом запуске скачивает ядро Pyodide с CDN — нужен интернет; дальше оно остаётся в памяти вкладки.
- Python-воркер изолирован от страницы и сети, но это не полноценная песочница безопасности: не запускайте туда чужой код.
- Мини-тест после главы берёт три случайных вопроса из банка раздела и не записывается в прогресс.
